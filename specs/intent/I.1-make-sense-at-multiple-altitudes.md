# I.1 — Make sense of my finances at multiple altitudes

## why

Numbers alone don't change behavior. "$340 on coffee" is information; "those purchases cluster on stressful Mondays after a long weekend" is insight; "your caffeine intake doubled the month you started a new job" is the kind of frame that actually moves a person to act. The project exists so I can move freely between altitudes — see categories, see merchants, see patterns, see the behavioral story — without rebuilding the analysis each time.

## success criteria

- Comprehensive spending analysis is available in a single command (`/analyze`).
- Behavioral framing is the default voice, not an add-on (`/habits`, `/perspectives`).
- Specialized lenses exist for budgeting, subscriptions, and salary affordability.
- Recommendations cite research, not generic finance advice (Oaten &amp; Cheng, Kuchler &amp; Pagel, Wansink).
